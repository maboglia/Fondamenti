# Agile

> 
> Origine: https://github.com/maboglia/Fondamenti/blob/master/050_agile.md

L'approccio Agile favorisce l'adattamento continuo, la collaborazione e la consegna incrementale del lavoro.

## Principi principali

- iterazione continua
- feedback rapido
- collaborazione tra team
- valore per il cliente
- flessibilità rispetto ai cambiamenti
- pianificazione adattiva

## Metodologie e pratiche

- Scrum
- Kanban
- Extreme Programming (XP)
- Lean Software Development
- DevOps culture

## Vantaggi

- maggiore reattività ai cambiamenti
- miglioramento continuo
- collaborazione più efficace
- consegna incrementale di valore

## Uso nel mondo dello sviluppo software

Agile è oggi lo standard per molti team di sviluppo, in particolare per progetti complessi e in rapida evoluzione.
