# CSS3 e Styling Avanzato

> Documento migrato dal repository originale nella root del progetto.
> 
> Origine: https://github.com/maboglia/Fondamenti/blob/master/023_CSS3.md

CSS3 è il linguaggio di stile moderno che consente di controllare l'aspetto e il layout delle pagine web.

## Temi principali

- selettori
- box model
- positioning
- flexbox
- grid
- animazioni
- transizioni
- media queries
- transform

## Metodologie

- BEM (Block Element Modifier)
- OOCSS (Object Oriented CSS)
- Atomic CSS
- Utility-first

## Obiettivo

Creare interfacce visualmente attraenti, responsive e performanti.
