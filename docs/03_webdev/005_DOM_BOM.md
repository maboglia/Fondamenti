DOM (Document Object Model) e BOM (Browser Object Model) sono le interfacce JavaScript per interagire con il browser.

## DOM - Document Object Model

Rappresenta la struttura dell'HTML come un albero di nodi che possono essere manipolati con JavaScript.

- selezione elementi
- modifica contenuto
- manipolazione attributi
- event handling
- creazione elementi

## BOM - Browser Object Model

Provvede accesso alle funzionalità del browser stesso.

- window object
- navigator
- location
- history
- screen
- cookie
- local storage

## Utilizzo

DOM e BOM sono essenziali per creare pagine web interattive e dinamiche.
