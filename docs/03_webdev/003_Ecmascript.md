# ECMAScript e Versioni di JavaScript

> Documento migrato dal repository originale nella root del progetto.
> 
> Origine: https://github.com/maboglia/Fondamenti/blob/master/024_Ecmascript.md

ECMAScript è lo standard ufficiale di JavaScript, aggiornato regolarmente con nuove feature.

## Versioni rilevanti

- ES5 (2009) - standard consolidato
- ES6/ES2015 - grande aggiornamento
- ES2016-2023 - miglioramenti annuali

## Feature moderne

- arrow functions
- destructuring
- template literals
- async/await
- classes
- modules
- spread operator
- optional chaining

## Importanza

Comprendere l'evoluzione di JavaScript è essenziale per scrivere codice moderno e leggibile.
