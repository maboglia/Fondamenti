# Middleware

> Documento migrato dal repository originale nella root del progetto.
> 
> Origine: https://github.com/maboglia/Fondamenti/blob/master/028_middleware.md

Il middleware è un componente software che intercetta e processa richieste e risposte tra il client e il server.

## Concetto

Il middleware agisce come un "intermediario" che può:
- elaborare i dati
- autenticare l'utente
- validare i dati
- gestire errori
- registrare informazioni
- comprimere risposte

## Utilizzo

- Express.js
- Django
- Flask
- ASP.NET
- Node.js

## Catena di middleware

I middleware possono essere concatenati per formare una pipeline di elaborazione.

## Importanza

Il middleware consente di scrivere codice modulare, riutilizzabile e facile da mantenere.
