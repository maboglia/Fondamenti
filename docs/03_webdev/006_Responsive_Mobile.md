Responsive Web Design (RWD) consente alle pagine web di adattarsi a diversi dispositivi e dimensioni di schermo.

## Concetti principali

- fluid grids
- flexible images
- media queries
- mobile-first approach
- breakpoints
- viewport meta tag

## Mobile First

Progettare prima per mobile, poi espandere per desktop:
- caricamento più veloce
- priorità ai contenuti essenziali
- migliore user experience
- SEO friendly

## Strumenti

- CSS media queries
- flexbox e grid
- responsive typography
- responsive images

## Obiettivo

Garantire un'esperienza ottimale su qualsiasi dispositivo e dimensione di schermo.
