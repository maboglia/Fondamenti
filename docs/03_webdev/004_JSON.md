# JSON - JavaScript Object Notation

> Documento migrato dal repository originale nella root del progetto.
> 
> Origine: https://github.com/maboglia/Fondamenti/blob/master/025_JSON.md

JSON è un formato di scambio dati leggero e ampiamente utilizzato nelle API web.

## Caratteristiche

- facilmente leggibile
- supportato da tutti i linguaggi moderni
- basato su coppie chiave-valore
- supporta array e oggetti annidati

## Utilizzo

- API REST
- configurazioni
- database
- trasmissione dati
- serializzazione

## Sintassi

- stringhe, numeri, booleani, null
- array: `[]`
- oggetti: `{}`

## Importanza

JSON è fondamentale per la comunicazione tra client e server nelle applicazioni web moderne.
