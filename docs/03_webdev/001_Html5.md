# HTML5

HTML5 è il linguaggio di markup moderno per la creazione di pagine web semantiche e accessibili.

## Elementi principali

- struttura semantica
- form
- media
- canvas
- web storage
- geolocation
- web workers

## Best practices

- usare elementi semantici corretti
- garantire accessibilità
- validare il markup
- ottimizzare le prestazioni

## Importanza

HTML5 è il fondamento di tutte le pagine web moderne e fornisce gli strumenti per creare esperienze utente ricche e interattive.
