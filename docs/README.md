# Documentazione

Questa cartella contiene il materiale didattico teorico del repository Fondamenti, organizzato per argomento e livello.

## Struttura

- `01_fondamenti/` — fondamenti, algoritmi, paradigmi, OOP
- `02_programmazione/` — variabili, funzioni, strutture dati, bash
- `03_webdev/` — HTML, CSS, JavaScript, REST, HTTP
- `04_engineering/` — regex, GitHub, debug, Linux, LLM, blockchain
- `05_agile_management/` — agile, Scrum, pomodoro, competenze
- `06_skills_trasversali/` — soft skills, sostenibilità, pensiero critico

## Stato

Questa struttura è stata preparata in fase di ristrutturazione. I file legacy presenti nella root saranno migrati gradualmente in questa sezione.
