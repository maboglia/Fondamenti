# Programmazione Orientata agli Oggetti

> Documento migrato dal repository originale nella root del progetto.
> 
> Origine: https://github.com/maboglia/Fondamenti/blob/master/005_OOP.md

La programmazione orientata agli oggetti (OOP) organizza il codice in oggetti e classi, costruiti per modellare entità reali o concettuali.

## Concetti fondamentali

- classe
- oggetto
- attributi
- metodi
- incapsulamento
- ereditarietà
- polimorfismo

## Vantaggi

- modularità
- riuso del codice
- organizzazione del sistema
- gestione della complessità
- manutenzione più semplice

## Esempio di concetto

Una classe definisce il modello, mentre un oggetto è un'istanza concreta di quella classe.

Le diverse note storiche della root sono state unite in questa sezione per offrirne una lettura più ordinata e performante.
