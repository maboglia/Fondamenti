# Pensiero Computazionale

> Documento migrato dal repository originale nella root del progetto.
> 
> Origine: https://github.com/maboglia/Fondamenti/blob/master/030_PensieroComputazionale.md

Il pensiero computazionale è un approccio logico per risolvere problemi attraverso astrazione, decomposizione, simulazione e algoritmo.

## Caratteristiche principali

- scomposizione del problema
- astrazione
- pattern recognition
- algoritmi e procedure
- iterazione e ricorsione
- pensiero critico e logico

## Applicazioni

Il pensiero computazionale è utile in molti campi:
- informatica
- matematica
- ingegneria
- scienze
- analisi dei dati
- automazione
