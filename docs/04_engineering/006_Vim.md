# Vim - Editor di Testo

> Documento migrato dal repository originale nella root del progetto.
> 
> Origine: https://github.com/maboglia/Fondamenti/blob/master/031_vim.md

Vim è un editor di testo potente e veloce, disponibile su quasi tutti i sistemi Unix/Linux.

## Modalità

- **Normal**: navigazione e editing (default)
- **Insert**: inserimento di testo
- **Visual**: selezione di testo
- **Command**: esecuzione di comandi

## Comandi essenziali

### Navigazione
- `h` `j` `k` `l` - movimento (sinistra, giù, su, destra)
- `w` - inizio parola successiva
- `b` - inizio parola precedente
- `0` - inizio linea
- `$` - fine linea
- `gg` - inizio file
- `G` - fine file

### Editing
- `i` - insert mode prima del cursore
- `a` - insert mode dopo il cursore
- `o` - nuova linea sotto
- `O` - nuova linea sopra
- `x` - cancella carattere
- `dd` - cancella linea
- `u` - undo
- `Ctrl+r` - redo

### Search e Replace
- `/pattern` - cerca
- `n` - prossima occorrenza
- `:s/old/new/` - sostituzione
- `:%s/old/new/g` - sostituzione globale

## Vantaggi

- velocità
- disponibile ovunque
- personalizzabile
- potente

## Curva di apprendimento

Vim ha una curva di apprendimento ripida ma vale la pena impararlo.
