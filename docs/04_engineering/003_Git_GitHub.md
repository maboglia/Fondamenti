Git è il sistema di versionamento più diffuso, mentre GitHub è la piattaforma che lo ospita e aggiunge funzionalità collaborative.

## Concetti base di Git

- repository
- commit
- branch
- merge
- remote
- staging area

## Comandi essenziali

- `git init` - inizializzare repo
- `git add` - aggiungere files
- `git commit` - salvare cambamenti
- `git push` - inviare al remote
- `git pull` - scaricare dal remote
- `git branch` - creare/gestire branch
- `git merge` - unire branch

## GitHub features

- pull requests
- issues tracking
- wiki
- pages
- actions (CI/CD)
- discussions
- security alerts

## Workflow collaborativo

1. Fork del repository
2. Creare un branch feature
3. Fare commit dei cambiamenti
4. Push del branch
5. Creare una pull request
6. Review e discussione
7. Merge nel main

## Best practices

- commit messages chiari
- atomic commits
- branch naming conventions
- code reviews
- issue tracking
