Comandi essenziali per lavorare con il sistema operativo Linux da linea di comando.

## File e Directory

- `ls` - lista file
- `pwd` - path corrente
- `cd` - cambia directory
- `mkdir` - crea directory
- `rm` - elimina file
- `rmdir` - elimina directory
- `cp` - copia file
- `mv` - sposta/rinomina file
- `cat` - mostra contenuto file
- `find` - cerca file
- `grep` - cerca pattern

## Permessi

- `chmod` - modifica permessi
- `chown` - cambia proprietario
- `chmod +x` - rendi eseguibile

## Gestione Processi

- `ps` - lista processi
- `kill` - termina processo
- `bg` - background
- `fg` - foreground
- `top` - monitor sistema
- `htop` - monitor avanzato

## Rete

- `ping` - test connessione
- `ifconfig` - configurazione rete
- `netstat` - statistiche rete
- `ssh` - remote shell
- `scp` - copia remota

## Utilità

- `man` - manuale
- `sudo` - super user
- `tar` - archivio
- `zip/unzip` - compressione
- `wget/curl` - download
- `git` - versionamento

## Pipe e Redirezione

- `|` - pipe output a command
- `>` - redirect output a file
- `<` - redirect input da file
- `>>` - append output a file

## Tips

- `history` - cronologia comandi
- `Tab` - autocompletamento
- `Ctrl+C` - interrompi
- `Ctrl+Z` - pause
