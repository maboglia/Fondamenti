# Espressioni

> 
> Origine: https://github.com/maboglia/Fondamenti/blob/master/204_espressioni.md

Una espressione è una combinazione di valori, variabili e operatori che produce un risultato.

## Esempi

- `a + b`
- `x > 10`
- `condizione && altroControllo`
- `somma * 2`

## Importanza

Le espressioni sono alla base di:
- assegnazioni
- condizioni
- calcoli
- decisioni logiche
- trasformazioni dei dati

Già presenti nella root del repo, ora sono stati organizzati in una sezione più tematica e accessibile.
