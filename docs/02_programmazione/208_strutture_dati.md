# Strutture Dati

> Documento migrato dal repository originale nella root del progetto.
> 
> Origine: https://github.com/maboglia/Fondamenti/blob/master/208_strutture_dati.md

Le strutture dati sono modi per organizzare e gestire i dati all'interno di un programma.

## Esempi classici

- array
- liste
- pile
- code
- mappe
- insiemi
- grafi

## Obiettivo

Scegliere la struttura dati più adatta a un problema per migliorare prestazioni, correttezza e leggibilità del codice.

Il materiale originario è stato consolidato in una sezione dedicata al nucleo della programmazione.
