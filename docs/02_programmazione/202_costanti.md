# Costanti

> Documento migrato dal repository originale nella root del progetto.
> 
> Origine: https://github.com/maboglia/Fondamenti/blob/master/202_costanti.md

Le costanti sono valori che non cambiano durante l'esecuzione del programma.

## Utilizzo

Le costanti sono utili per definire valori fissi come:
- massimi e minimi
- configurazioni
- stringhe costanti
- parametri di sistema

## Vantaggi

- leggibilità del codice
- riduzione di errori
- manutenzione semplificata
