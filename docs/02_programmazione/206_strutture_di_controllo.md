# Strutture di Controllo

> Documento migrato dal repository originale nella root del progetto.
> 
> Origine: https://github.com/maboglia/Fondamenti/blob/master/206_strutture_di_controllo.md

Le strutture di controllo permettono di decidere il flusso di esecuzione di un programma.

## Strutture principali

- condizioni
- selezioni
- cicli
- branch
- interruzioni e continuazioni

## Esempi

- if / else
- switch
- for
- while
- do while

L'uso corretto delle strutture di controllo è fondamentale per scrivere software comprensibile ed efficiente.
