# Corso JavaScript

Percorso didattico dedicato a JavaScript.

## Obiettivo

Acquisire padronanza del linguaggio JavaScript e dei concetti del web development moderno.

## Prerequisiti

È utile aver studiato almeno i fondamenti del coding e la logica di programmazione:

## Struttura del corso

- Base del linguaggio
- DOM, eventi e browser
- ES6 ed evoluzione del linguaggio
- Fetch, API e networking
- Applicazioni web pratiche

## Come usare questo corso

1. Studia i fondamenti della programmazione.
2. Poi passa alla parte web e JS.
3. Applica gli esercizi con piccoli script e mini app.
4. Consulta la documentazione di riferimento quando servono esempi o sintassi.
