# Corso PHP

Percorso didattico dedicato a PHP.

## Obiettivo

Imparare lo sviluppo server-side con PHP e le sue principali applicazioni web.

## Struttura del corso

- sintassi PHP
- variabili, funzioni, database
- form e request HTTP
- sessioni e autenticazione
- architetture web in PHP

## Come usare questo corso

1. Studia la parte di programmazione e logica.
2. Poi passa alla parte web e PHP.
3. Fai esercizi che combinano HTML, PHP e database.
4. Consulta gli appunti di supporto quando serve un ripasso rapido.
