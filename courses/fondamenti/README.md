# Corso Fondamenti di Programmazione

Il corso base del repository.

## Obiettivo

Questo percorso introduce i concetti fondamentali della programmazione: logica, algoritmi, dati, controllo del flusso, funzioni e paradigma di programmazione.

## Prerequisiti

Nessuno, è il percorso iniziale consigliato.

1. Inizia dalla parte teorica.
2. Studia i concetti base prima di passare agli esercizi.
