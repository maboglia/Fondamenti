# Corso Java

Percorso didattico dedicato a Java.

## Obiettivo

Approfondire la programmazione orientata agli oggetti, le collezioni, le eccezioni e le pratiche di sviluppo Java.

## Struttura del corso

- OOP e classi
- collezioni e strutture dati
- eccezioni
- package e modularità
- pratiche di sviluppo Java

## Come usare questo corso

1. Studia la parte teorica sulla programmazione e OOP.
2. Applica i concetti con esercizi Java progressivi.
3. Riutilizza gli appunti per fare ripasso rapido quando necessario.
