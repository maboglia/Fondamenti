# Glossario essenziale Bash

- **Shell**: programma che interpreta comandi e consente di interagire con il sistema.
- **Bash**: Bourne Again SHell, una delle shell disponibili nei sistemi Unix-like.
- **Terminale**: interfaccia testuale attraverso cui si interagisce con una shell.
- **Script**: file contenente una sequenza di comandi.
- **Shebang**: prima riga, ad esempio `#!/usr/bin/env bash`, che indica l'interprete.
- **Variabile**: nome associato a un valore.
- **Pipeline**: collegamento tra comandi tramite `|`.
- **Redirezione**: deviazione di input o output verso file o altri flussi.
- **Exit status**: codice numerico restituito da un comando; convenzionalmente 0 indica successo.
- **Processo**: istanza in esecuzione di un programma.
- **Permesso**: regola che determina le operazioni consentite su un file o directory.
- **Cron**: servizio tradizionale per pianificare attività periodiche.
