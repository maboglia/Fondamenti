# Esercitazioni progressive

## Livello 1 – Base
1. Stampare un messaggio personalizzato.
2. Creare una directory di laboratorio e mostrare il percorso.
3. Creare un file con tre righe e visualizzarne le prime due.
4. Mostrare i permessi di uno script e renderlo eseguibile.

## Livello 2 – Intermedio
1. Leggere un nome e salutare l'utente.
2. Stabilire se un numero è pari o dispari.
3. Stampare i numeri da 1 a 10.
4. Sommare due argomenti passati da riga di comando.
5. Usare `case` per classificare un giorno della settimana.

## Livello 3 – Avanzato
1. Definire una funzione di saluto.
2. Cercare una parola in un file di testo.
3. Contare le righe corrispondenti e salvare il risultato.
4. Copiare un file solo se esiste.
5. Leggere un file riga per riga e selezionare quelle che iniziano con maiuscola.

## Livello 4 – Mini-progetti
1. Backup datato di file `.txt`.
2. Contatore dei livelli di log in un file di laboratorio.
3. Rinomina controllata di immagini `.jpg`.
4. Menu interattivo per elencare file e cercare parole.
5. Report dei permessi di file in una directory di test.

Per ogni esercizio: descrivere input, output atteso, casi limite e verifiche.
